# Прогнозирование риска задержки доставки заказов (CargaPronto)

## 📋 О проекте

Проект посвящён разработке ML-модели для системы поддержки принятия решений логистической компании. Модель позволяет заранее выявлять заказы с высоким риском задержки доставки, что помогает логистическому департаменту своевременно реагировать и снижать операционные издержки.

**Тип задачи:** бинарная классификация (обучение с учителем)
**Целевая переменная:** `late_delivery_risk` (1 — заказ доставлен с задержкой; 0 — доставлен вовремя)
**Целевая метрика:** ROC-AUC > 0.75

## 📊 Данные

Используются два датасета в формате CSV:

### `ds_s18_customers.csv` — профили клиентов (20 652 записи)

## 🔬 Методология

### 1. EDA (исследовательский анализ)
- Проверка баланса классов (54.8% / 45.2% — без дисбаланса)
- Географический аудит: удаление аномальных координат по долготе (−125…−20)
- Анализ корреляций (φK-матрица): ключевой предиктор — `shipping_mode` (0.654)
- Исследование `return_rate`, координат клиентов, поведенческих паттернов
- Проверка гипотезы о «чёрных дырах» на карте (не подтвердилась)

### 2. Разделение выборки
Классическое разделение **60/20/20** через `GroupShuffleSplit` по `customer_id`, чтобы исключить утечку данных между выборками (один клиент не попадает в train и test одновременно).

### 3. Кластеризация

#### 🌍 Географическая (`KMeans`, K=4/8)
- Признаки: `customer_lat`, `customer_lon`
- Масштабирование через `StandardScaler`, обучение только на train
- Визуализация кластеров с центроидами на карте

#### 👥 Поведенческая (`KMeans`, K=6/30)
- Признаки: `recency`, `total_orders`, `total_sales`, `return_rate`, `avg_discount`
- Выделены сегменты клиентов:
  - VIP-клиенты
  - Постоянные клиенты
  - «Проблемные» (высокий return_rate)
  - Ушедшие (высокий recency)
  - Новички со скидкой
  - Органические новички
- Визуализация сегментов через **t-SNE**

### 4. Моделирование

**Базовая модель (только параметры заказа):**
| Модель | ROC-AUC |
|---|---|
| Логистическая регрессия + Target Encoding | 0.7251 |
| **CatBoostClassifier** | **0.7503** |

**Финальная модель (+ кластерные признаки):**
| Модель | ROC-AUC |
|---|---|
| Логистическая регрессия + Target Encoding | 0.7286 |
| **CatBoostClassifier** | **0.7541** |

### 5. Подбор гиперпараметров кластеризации
Перебор комбинаций `geo_k ∈ {4, 8, 12, 20}` × `profile_k ∈ {6, 12, 20, 30}`.

**Лучшая комбинация:** `geo_k=8`, `profile_k=30` → **ROC-AUC = 0.7676** на валидации.

### Ключевые выводы

shipping_mode — главный предиктор задержки (φK = 0.654): тип доставки напрямую определяет приоритет обработки.

Категория товара и цена практически не влияют на риск задержки — логистика работает одинаково для всех типов продукции.

География и лояльность клиента в чистом виде слабо коррелируют с задержками, но в виде кластеров дают значимый прирост качества.

Кластерные признаки (geo_cluster, profile_cluster) в виде категориальных переменных работают лучше, чем в виде числовых.

Тонкая детализация клиентских сегментов (30 кластеров) даёт больший прирост, чем мелкая геосегментация (8 зон — оптимум).

Найденная группа клиентов с ~93% возвратов — потенциальный маркер системной проблемы в логистике.
